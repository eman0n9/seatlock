# SeatLock frontend

Next.js 16 frontend for SeatLock.

```powershell
npm.cmd ci
npm.cmd run dev
```

The development server is available at http://localhost:3000.

Copy `.env.example` to `.env.local` to use the real API. Without `.env.local`, API modes default to mock data.

Available scripts:

- `npm run dev` — development server
- `npm test` — unit tests
- `npm run build` — production build
- `npm start` — serve a production build

See the repository root README for the complete stack setup.
